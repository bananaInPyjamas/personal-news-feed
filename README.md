# Personal News Feed

A personalized daily news homepage researched and updated by a scheduled Codex task, with GitHub Pages as the static publishing layer.

## Status

Initial project setup. Content preferences, sources, editorial rules, and the first interface will be defined collaboratively.

## Intended workflow

1. Codex reviews current news using the agreed interests and sources.
2. Codex writes a sourced daily edition into this repository.
3. The edition is validated, committed, and pushed to GitHub.
4. GitHub Pages publishes the static homepage.

The repository itself will not contain news-retrieval or AI-summarization services.
